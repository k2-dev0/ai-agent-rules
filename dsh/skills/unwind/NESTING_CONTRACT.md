# ネスト候補の検出

親が渡したrepository・HEAD・本体コードのpathだけを検出する。入力不足・読めないpathは失敗として返す。

調査範囲を広げず、機能調査・要件や設計の判断・修正案は返さない。Codexのshellは本契約・共通制約・対象fileの読み取りだけに使う。

| 制御構造 | 深さ |
|---|---|
| if/else、loop、switch、try/catch/finally | 同じ実行経路の重なり |
| else if連鎖 | 1つの選択 |
| case | switchより深く数えない |
| 関数・method・callback | 内部を独立して数える |

括弧数だけで判定しない。全対象を読み、HEAD・検出済みpath・未読pathと、3段以上の候補のfile・行・最大深さ・到達条件を返す。全対象を検出して候補ゼロなら「3段階以上の制御フローネストなし」と返す。
