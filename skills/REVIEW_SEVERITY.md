# レビューの重大度

成立条件、直接の実害、影響範囲、回避・回復の容易さで判定する。明示要件・規約への違反、test不足、修正対象であることだけではhigh以上にしない。

| severity | 判断基準 |
|---|---|
| `critical` | 重大なデータ損失、機密漏洩、認可回避など、甚大な被害につながる具体的な経路がある |
| `high` | 通常の対応入力・標準手順で主要機能が使えない、広範に誤結果を返す、重大な公開互換性が壊れるなど、直接の影響が大きく回避も難しい |
| `medium` | 限定的な入力・環境・経路で起きる局所的かつ回復可能な不具合、補助検査の欠落・誤検出。明示要件内の問題も含む |
| `low` | 挙動・成果物の正しさに影響しない保守性・明瞭性の問題 |

`critical`・`high`は`condition`と`impact`に重大な影響へ至る直接の因果を示す。仮想的な将来事故を重ねて昇格しない。反対に、重大な被害の具体的な経路がある問題を発生頻度だけで格下げしない。test・検査器の問題も、検査の重要そうな名前ではなく、確認できた影響で判定する。
