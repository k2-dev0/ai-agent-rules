# サブエージェント

- 実装は`implementer`、ネスト候補抽出は`nesting-reviewer`。CodexはLuna/max、ClaudeはSonnet/maxの専用定義を使う。別role・モデル・effort、設定上書き、resume、一括起動は使わない。
- 目的・対象path・完了条件・必要な事実だけをbriefへ渡す。会話全体を継承せず、コード・規約は正本を参照させる。追加委任は禁止。
- 子の結果は変更path・要点・検証結果・未解決事項だけ受け取る。全文ログ・中間出力を再取得しない。
- 待機中は独立した必要作業を進める。作業がなければ完了通知または60秒以上の待機を使う（tool・上位指示の上限まで）。複数の待機先を扱えるtoolではまとめ、返却cursorがあれば次回へ渡す。
- 即時snapshotは初回確認か新しい事実の確認に限る。進展なしの短周期poll、同じ結果の再読、催促、待機だけのモデル交代は禁止。完了を受けたら元の作業を続ける。
