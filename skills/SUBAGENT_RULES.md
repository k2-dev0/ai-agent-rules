# サブエージェント

- 子の用途は実装方針確定後の難易度調査（`difficulty-evaluator`）、独立コードレビュー（`code-reviewer` / `deep-reviewer`）、設計監査（`design-reviewer`）、ネスト候補抽出（`nesting-reviewer`）。方針決定のための一般調査・実装・修正・Git操作はメインが行う。
- 子は1体ずつ新規起動し、完了までメインの作業も止める。完了確認後にだけ次の作業へ進む。
- 実行中の環境の専用role・起動toolだけを使う。Codexの起動失敗をClaudeで代替せず、Claudeの起動失敗もCodexで代替しない。未登録ならその環境の定義・配置を確認し、入力拒否なら同じ環境の入力契約を確認する。
- 各roleの入力契約に従ってbriefを渡す。会話全体を継承せず、コード・規約は正本を参照させる。追加委任は禁止。
- 子の結果は各roleの返却契約に従って最終結果だけ受け取る。全文ログ・中間出力を再取得しない。
- サブエージェントの完了通知または60秒以上の待機を使う（tool・上位指示の上限まで）。返却cursorがあれば次回へ渡す。
- 即時snapshotは初回確認か新しい事実の確認に限る。進展なしの短周期poll、同じ結果の再読、催促、待機だけのモデル交代は禁止。完了を受けたら元の作業を続ける。
