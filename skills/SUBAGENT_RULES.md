# サブエージェント

- 実装・修正はメインが行い、[モデル選択](MODEL_SELECTION.md)で切り替える。子を使うのは広い読み取りの文脈隔離・独立レビューが必要な場合だけ。編集・Git操作を委任しない。
- 並列実行は禁止。子は1体ずつ新規起動し、完了までメインの作業も止める。完了確認後にだけ次の作業・子の起動へ進む。
- コードレビューは[独立レビュー](INDEPENDENT_REVIEW.md)の専用role、設計監査は[ponytail](ponytail/SKILL.md)の`design-reviewer`、ネスト候補抽出は`nesting-reviewer`、その他の調査は利用可能な読み取り用agentを使う。background・一括起動・resumeは使わない。
- 目的・対象path・完了条件・必要な事実だけをbriefへ渡す。会話全体を継承せず、コード・規約は正本を参照させる。追加委任は禁止。
- 子の結果は変更path・要点・検証結果・未解決事項だけ受け取る。全文ログ・中間出力を再取得しない。
- サブエージェントの完了通知または60秒以上の待機を使う（tool・上位指示の上限まで）。返却cursorがあれば次回へ渡す。
- 即時snapshotは初回確認か新しい事実の確認に限る。進展なしの短周期poll、同じ結果の再読、催促、待機だけのモデル交代は禁止。完了を受けたら元の作業を続ける。
